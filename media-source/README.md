# Исходные материалы

Здесь лежит то, что **не должно уезжать на сайт**: оригиналы снимков,
фотографии на проверке и портрет тренера, пока он заменён абстрактным
плейсхолдером.

Всё в `public/` отдаётся посетителю как есть — статическая сборка не умеет
пересжимать картинки на лету. Поэтому в `public/media` держим только те
файлы, которые действительно выводятся на страницах.

Понадобится снимок на сайте — переносим его в `public/media/<раздел>/`
предварительно уменьшив до нужного размера.
