# Посадочная страница для Яндекс Директа

Адрес: `/probnoe-zanyatie/`. Исходники: `src/app/probnoe-zanyatie/page.tsx`,
блоки в `src/components/sections/TrialLanding.tsx`, урезанные шапка и подвал —
`LandingHeader.tsx` и `LandingFooter.tsx` (подключаются в `layout.tsx` через
`ChromeSwitch.tsx` только на этом адресе).

## Зачем

Одна задача: родитель приходит из объявления и оставляет заявку на пробное
занятие. Поэтому на странице нет меню и ссылок на разделы сайта, а форма
стоит сразу под первым экраном. Остальное собрано из готовых компонентов:
форма `FinalCta` (`LeadForm`), отзывы `Reviews`, вопросы `Faq`, выбор времени
и направления через `SlotBookButton` и `ProgramBookButton`.

Порядок блоков: первый экран (заголовок, кнопка, время, направления), форма,
«Почему мы», отзывы, как добраться, четыре вопроса, подвал. На телефоне
липкая кнопка `MobileCta` показывается после первого экрана и ведёт к форме.

## Индексация

* `robots: { index: false, follow: true }` в самой странице;
* в `sitemap.ts` страницы нет (там явный список, добавлять её не надо);
* в `robots.txt` страница НЕ закрыта: закрытую страницу робот не откроет и
  noindex не увидит;
* canonical на саму себя (даёт `pageMetadata`, домен берётся из `site.url`).

Это стережёт тест `src/app/direct-landing.test.ts`.

## Ссылка для объявлений

```
https://www.primeswim.ru/probnoe-zanyatie/?utm_source=yandex&utm_medium=cpc&utm_campaign={campaign_id}&utm_content={ad_id}&utm_term={keyword}
```

Домен с www: он каноничный (`public/CNAME`), голый `primeswim.ru` отдаёт 301.

Макросы Директа: `{campaign_id}` — номер кампании, `{ad_id}` — номер
объявления, `{keyword}` — ключевая фраза. Как их режет
`src/lib/campaign-source.ts`:

* сохраняются только `utm_source`, `utm_medium`, `utm_campaign`,
  `utm_content`, `utm_term` и `yclid`; всё остальное в адресе отбрасывается;
* значение каждой метки обрезается до 60 символов (длинная фраза в
  `{keyword}` придёт обрезанной);
* кириллица остаётся читаемой, экранируются только `%`, `&`, `+`, `=`;
* метки живут в `sessionStorage` один визит и уходят в заявку в поле
  «Источник»; кроме того, сам по себе `yclid` Директ добавляет к ссылке сам,
  если в кампании включена разметка ссылок (проверить в кабинете).

Если открыть ссылку руками, макросы останутся буквальными (`{campaign_id}`):
в живых объявлениях Директ подставляет значения сам.

## Что владелец делает в кабинете Директа

1. В объявлениях кампании на сайт заменить ссылку на ту, что выше.
2. Проверить, что цель `lead_delivered` выбрана целью кампании (на ней
   учится стратегия) и счётчик Метрики 111745879 привязан к кампании.
3. Включить автоматическую разметку `yclid`, если выключена.

В Директ и Метрику агент не заходил: ничего из этого не проверено.

## Как смотреть результат в Метрике

Отчёты, Стандартные отчёты, Источники, Метки UTM (или «Конструктор
отчётов»: группировка по `UTMCampaign`, `UTMContent`, `UTMTerm`), метрика
«Достижения цели» с целью `lead_delivered`. Цель отправляется только когда
приёмник заявок ответил номером заявки, то есть это настоящая заявка, а не
клик. Клики по записи (`cta_booking`), телефону и маршруту считаются
существующими целями, новых целей страница не заводит.

Точное совпадение заявки с кликом можно сверять по полю «Источник» в чате
школы (там те же `utm_campaign` и `yclid`).

## Ограничения

* Метрика видит только тех, кто принял cookie в баннере. Отказавшие или не
  ответившие в отчёт не попадают, поэтому заявок по Метрике будет меньше,
  чем реально пришло. Полную картину даёт поле «Источник» в самих заявках:
  оно не зависит от согласия на cookie.
* Страница noindex: найти её в поиске нельзя, только по ссылке из рекламы.
* Фото: только бассейн МГИК и тренер, без узнаваемых детей. Галерею и
  съёмки с детьми на странице не использовать без согласий родителей на
  коммерческое использование.
