# Composio для PRIME SWIM: аудит и минимальная архитектура

Состояние проверено 3 сентября 2026 года. Документ хранит только технические
решения. Секретов, токенов и персональных данных клиентов здесь быть не должно.

## Результат аудита

### Подключено

- В Claude Code установлен официальный плагин `composio@composio` версии
  `0.2.4` на уровне пользователя.
- В `.mcp.json` проекта добавлен официальный удалённый сервер
  `https://connect.composio.dev/mcp` под именем `composio-connect`.
- Проектный MCP одобрен в Claude Code; OAuth завершён, и проверка
  `claude mcp list` показывает `composio-connect` в состоянии `Connected`.
- В личном разделе Composio `Connected` подтверждено: `No connected apps yet`.
  В разделе shared connections также нет подключений. Значит Gmail, Google
  Calendar, GitHub и другие внешние аккаунты сейчас не подключены.
- Для Composio For You кабинет показывает бесплатный режим без банковской
  карты и подписки.
- Живая проверка 3 сентября 2026 года: мета-поиск Composio отвечает и отдаёт
  план и схемы инструментов Gmail, но сам toolkit возвращает
  `has_active_connection: false`. Транспорт исправен, аккаунтов нет.

Официальный локальный CLI не установлен. Его инсталлятор не поддерживает
Windows без WSL, а WSL на компьютере отсутствует. Устанавливать отдельную
Linux-среду только ради Composio нецелесообразно: удалённый MCP решает задачу
проще.

### Рекомендуется подключить сейчас

1. **Gmail — первым и отдельно, но не через показанный default managed OAuth.**
   Проверенный 3 сентября 2026 года flow запросил полный `mail.google.com`,
   contacts scopes и дополнительные данные профиля (включая адреса, дату
   рождения и телефоны). Для read-only пилота это избыточно. Безопасные
   варианты: отдельный служебный Gmail без личной переписки либо custom Google
   OAuth только с `gmail.readonly`. Право отправки добавлять лишь после проверки
   чернового процесса.
2. **Google Calendar — вторым, если это реальный календарь администратора.**
   Чтение расписания и поиск свободных окон можно разрешить сразу. Создание,
   перенос и отмена событий — только после подтверждения.
3. **Google Drive/Sheets — после выбора реестра лидов.** Sheets подходит для
   небольшого процесса, но таблица с клиентскими данными должна иметь
   ограниченный доступ и не должна копироваться в GitHub. Drive подключать с
   минимальным `drive.file`, если не нужен поиск по всему диску.

### Подключить позже

- **Telegram.** В Composio есть бот-интеграция по API key (18 инструментов), а
  не доступ к обычному личному аккаунту Telegram. Она окупится только после
  решения, что заявки действительно принимает отдельный бот, и после проверки
  юридической схемы обработки данных.
- **Instagram / Facebook.** Instagram поддерживает только Business/Creator, а
  Facebook — Pages. Подключать после стабилизации контент-плана и Meta OAuth.
  Публикация, ответы и реакции всегда требуют подтверждения.
- **CRM.** Не выбирать HubSpot или другую CRM до фиксации реального процесса,
  объёма лидов и источника истины. Иначе появится второй несогласованный реестр.
- **Google Analytics.** Полезен для периодического отчёта, но сайт сейчас
  ориентирован на Яндекс Метрику. Подключение GA не заменит корректную доставку
  заявок и офлайн-конверсии.
- **GitHub через Composio.** Локальный Git и существующий remote уже дают Claude
  доступ к технической памяти. Composio здесь дублирует рабочий канал. Имеет
  смысл позже только для удалённых issue/PR-процессов; удаление веток, merge и
  изменение секретов запрещены без отдельного разрешения.

### Не подключать сейчас

- Универсальную CRM, таск-трекер и отдельную базу одновременно: это три места
  учёта одного лида.
- Платные генераторы видео/изображений через Composio: это premium-вызовы, а
  подготовку контента можно делать отдельно и загружать только готовые файлы.
- Browser automation для обычных API-задач: в актуальном тарифе это premium
  операция примерно по $0.70 за задачу и она менее надёжна, чем Gmail/Calendar
  API.
- VK через Composio: в актуальном публичном каталоге не подтверждён отдельный
  toolkit `VK`/`VKontakte`. Для VK позже нужен официальный API или отдельная
  проверенная интеграция.
- Дублирующие Google toolkits одновременно. Начать с Gmail; затем решить,
  удобнее ли отдельные узкие подключения или единый Google Super с тщательно
  проверенными scopes.

## Стоимость и ограничения

Для Platform-аккаунтов, созданных по новому тарифу, актуальный Free-план
Composio включает 100 000 tool calls,
50 000 trigger events, 3 участников и до 20 000 вызовов через managed apps в
месяц. Лимит жёсткий: после исчерпания работа останавливается, неожиданного
счёта нет. Pro стоит $29/месяц и включает расходный кредит, после чего действует
помесячная тарификация. Для первого ручного workflow PRIME SWIM Free-плана
достаточно с большим запасом. В используемом здесь режиме Composio For You
кабинет отдельно показывает бесплатное использование без карты и подписки.

Ограничения считаются отдельно у поставщиков: Google API quotas, Meta review,
тип Instagram-аккаунта, права GitHub и доступ бота Telegram. Composio не отменяет
эти правила. Соединения, созданные в Dashboard и через Connect MCP, могут быть
изолированы друг от друга, поэтому факт подключения всегда проверяется на той
же поверхности, с которой будет работать Claude.

Важно: настройка Enhanced Control ограничивает доступные агенту инструменты,
но сама по себе не доказывает сужение OAuth scopes. Перед подключением проверять
именно экран Google consent и URL scope, а не только список разрешённых tools.

## Архитектура Claude + Composio

```text
команда владельца
  -> Claude выбирает один нужный toolkit через meta-search
  -> узкий read с фильтром, лимитом и минимумом полей
  -> локальная классификация/сводка без сохранения ПДн
  -> черновик действия
  -> подтверждение владельца, если действие меняет внешний мир
  -> один точечный write
  -> проверка результата по ID/состоянию
  -> краткий итог без ПДн
```

По умолчанию разрешены чтение, поиск, анализ и подготовка текста в чате.
Подтверждение прямо перед действием обязательно для отправки сообщений,
публикации, создания/изменения/отмены событий, записей CRM, файлов и таблиц,
прав доступа, массовых операций, платежей, настроек, merge/push и удаления.
Пароли, OTP и OAuth подтверждает сам владелец.

## Экономия токенов

- Всегда начинать с `search`, а не загружать сотни схем инструментов.
- Фильтровать у источника: Gmail query, диапазон дат, unread/status, конкретный
  spreadsheet/calendar/repository ID.
- Первый запрос: IDs и короткие метаданные; полный объект — только для
  выбранных IDs.
- Лимит 10 элементов по умолчанию; пагинация только по явной необходимости.
- Не передавать Claude HTML, вложения и длинную переписку, если хватает темы и
  snippet.
- Повторно использовать IDs внутри одного запуска, но не кэшировать ПДн в
  репозитории или памяти.
- Для программно разбираемых workflows закреплять протестированную версию
  toolkit; для текста, который читает сам агент, допустим `latest`.

## Первая автоматизация: разбор входящих заявок

Команда `.claude/commands/prime-leads.md` реализует безопасный on-demand
сценарий:

1. Gmail search по непрочитанным письмам за 2 дня, максимум 10.
2. Отбор возможных обращений PRIME SWIM по теме и snippet.
3. Точечное чтение только отобранных сообщений.
4. Классификация и рекомендуемый ответ в чате.
5. Никаких изменений Gmail и никакой отправки.

До OAuth команда должна проверяться через `/prime-leads --dry-run` на
вымышленных данных. Проверка 3 сентября 2026 года в интерактивной сессии Claude
Code прошла полностью: три вымышленных письма разошлись по категориям
`новый лид`, `партнёрство` и `спам/не относится`, черновик составлен только для
лида, ПДн в ответе не повторены, внешние инструменты не вызывались. Цена,
адрес и расписание в черновик намеренно не подставлены и вынесены в вопросы
администратору. Более ранняя попытка через `claude -p` не дошла до ответа
модели из-за исчерпанного API credit balance: headless-режим оплачивается
API-кредитами, а не подпиской. После подключения Gmail первый боевой тест
остаётся read-only.

## Следующий безопасный шаг

Выбрать безопасную схему Gmail: отдельный служебный ящик либо custom OAuth с
`gmail.readonly`. После подключения выполнить `/prime-leads --dry-run`, затем
`/prime-leads за 2 дня`. Выбор Google-аккаунта и доступ к почте подтверждает
владелец. После успешного read-only теста отдельно решить, нужен ли scope для
создания draft; право отправки пока не выдавать. Проверенный default managed
flow отменён до выбора безопасного варианта; раздел Connected после отмены
по-прежнему показывает `No connected apps yet`.
